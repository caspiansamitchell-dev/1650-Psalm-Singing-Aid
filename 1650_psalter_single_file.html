About & Sources

The 1650 Psalter was approved for use by the Church of Scotland in 1650. This app uses public-domain Psalm text and public-domain KJV text.

  • 1650 Psalter reference: Reformed Standards / 1650Psalter resources.
  • KJV corpus: public-domain KJV JSON corpus.
  • Tune suggestions: compiled from common Scottish/Reformed psalmody references.

Recommendations are editorial aids, not a claim that every chapter has one uniquely correct Psalm.
